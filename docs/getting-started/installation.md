# Installation

```bash
pip install champi-stt
```

## Optional extras

| Extra | Packages |
|---|---|
| `webui` | FastAPI config UI |
| `vosk` | Offline wake word |
| `assemblyai` | AssemblyAI streaming |
| `imgui` | 3D energy sphere renderer |
| `torch` | PyTorch GPU acceleration |
| `nlp` | spaCy NLP features |
| `all` | Every optional extra |

```bash
pip install "champi-stt[webui,vosk]"
```
